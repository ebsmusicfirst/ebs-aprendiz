### Formatos que mais geram save no nicho musical
1. **Lista prática** — "5 erros de quem aprende sozinho", "3 sinais de que você está pronto para o próximo nível"
2. **Dado surpreendente + explicação** — EDU com fonte de autoridade
3. **Guia de decisão** — "Violão ou guitarra? Descubra qual é o seu"
4. **Desmistificador** — "Cifra não é difícil. Veja por quê."
5. **Motivacional com verdade incômoda** — "Você não precisa de talento. Precisa disso."

### Estrutura de hook que para o scroll (dados do nicho)
- **Afirmação contraintuitiva:** "Talento não existe para a ciência" → gera curiosidade
- **Dúvida real do público:** "Violão ou guitarra?" → responde algo que a pessoa já perguntou
- **Promessa de valor imediato:** "Em 5 minutos você vai ler qualquer cifra" → save garantido
- **Verdade incômoda:** "Por que você ainda não avançou sozinho" → MOT com empatia, não julgamento

## 🎣 Hooks de Referência por Carrossel

### MOT-02 — "Não precisa de talento"
**Framework:** PAS (Problema → Agitação → Solução)
**Público:** autodidatas travados + pais que acham que o filho "não tem dom"
```
Opção A: "Você acha que não tem talento para música. A ciência discorda."
Opção B: "Parou de tocar porque achou que não levava jeito? Era método, não talento."
Opção C: "Dom musical não existe. O que existe é método. E 14 anos provam isso."
```
**Por que funciona:** quebra crença limitante que é a principal objeção do público

### MET-03 — "Os 5 níveis"
**Framework:** Curiosidade + Identificação
**Público:** interessados que ainda não sabem onde estão
```
Opção A: "5 níveis. Você já está no primeiro — sem perceber."
Opção B: "A trilha EBS tem 5 níveis. Descubra em qual você está agora."
Opção C: "Do zero ao avançado: 5 estágios que todo músico passa. Qual é o seu?"
```
**Por que funciona:** cria pertencimento e convida para autoidentificação (comentários + saves)

### INS-04 — "Violão ou guitarra"
**Framework:** Dúvida real → Guia de decisão
**Público:** iniciantes com zero referência, pais comprando instrumento
```
Opção A: "Violão ou guitarra? Essa pergunta tem uma resposta certa para o seu caso."
Opção B: "Antes de comprar o instrumento: você precisa ler isso."
Opção C: "A diferença entre violão e guitarra vai além do som. Descubra qual é pra você."
```
**Por que funciona:** salva dinheiro + tempo = save garantido

### TEC-05 — "Cifra em 5 minutos"
**Framework:** Promessa de valor imediato
**Público:** autodidatas, adolescentes que tentam aprender por vídeo
```
Opção A: "Cifra parece complicado. Em 5 minutos, você vai ler qualquer uma."
Opção B: "Você não precisa saber teoria musical para tocar suas músicas favoritas. Só isso."
Opção C: "C, Am, F, G. Essas 4 cifras abrem 90% das músicas que você gosta."
```
**Por que funciona:** promessa de atalho real + alta salvabilidade

### CAP-06 — "Vagas abertas"
**Framework:** AIDA — Atenção + escassez suave
**Público:** todos — conversão
```
Opção A: "Novas vagas abertas no EBS Aprendiz. Por tempo limitado."
Opção B: "Se você está esperando o momento certo para começar — ele é agora."
Opção C: "Abrimos vagas para violão, guitarra, teclado e vocal. Veja como garantir a sua."
```
**Por que funciona:** direto, sem pressão agressiva, CTA claro

### EDU-07 — "Música e desempenho escolar" *(após pesquisa @analyst)*
**Framework:** Autoridade + dado surpreendente para pais
```
Opção A: "Harvard descobriu o que acontece com as notas de crianças que aprendem música."
Opção B: "Música melhora desempenho escolar. Não é opinião — é dado da Harvard Medical School."
Opção C: "Seu filho toca instrumento? Veja o que a ciência diz sobre as notas dele."
```
**Por que funciona:** fala direto com o gatilho dos pais (desenvolvimento cognitivo)
